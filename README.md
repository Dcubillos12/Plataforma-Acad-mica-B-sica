## Descripción del proyecto
Este repositorio corresponde al taller de trabajo colaborativo con Git y GitHub, enfocado en aplicar el flujo básico de desarrollo de software en un proyecto académico. La actividad busca comprender y practicar las buenas prácticas de control de versiones, coordinación entre desarrolladores y revisión del código antes de integrar cambios al repositorio principal.
